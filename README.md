## 🚀 Deployment to Vercel

The project includes pre-configured `vercel.json` and a static build pipeline:

```bash

# Run local development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```

### Deploying via Vercel CLI:
```bash
npx vercel --prod
```

Or connect the GitHub repository `https://github.com/Hritish-Narayanan/37-14-00-n115-48-30-w` in the Vercel Dashboard for instant continuous deployment.
